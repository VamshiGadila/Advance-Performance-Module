    autonumber
    actor User as 👤 User (Browser UI)
    participant NextJS as 💻 Next.js 16 (App Router)
    participant CorrFilter as 🆔 CorrelationIdFilter (MDC)
    participant Filter as 🛡️ Security Filter Chain (JWT)
    participant Ctrl as 🎮 REST Controller (@RestController)
    participant Val as 🏷️ Jakarta Validator (@Valid)
    participant Svc as ⚙️ Business Service (@Transactional)
    participant Repo as 🗄️ JPA Repository
    participant DB as 🐘 PostgreSQL Database
    participant ExHandler as 🚨 GlobalExceptionHandler

    User->>NextJS: Performs Action (Assign Goal / Update Progress)
    NextJS->>CorrFilter: HTTP Request [POST /api/manager/goals + JWT + JSON]
    CorrFilter->>CorrFilter: Generates X-Request-ID UUID & Puts in SLF4J MDC
    CorrFilter->>Filter: Proceeds down Filter Chain
    Filter->>Filter: Validates Token & Injects SecurityContext

    Filter->>Ctrl: Dispatches to Controller Method
    Ctrl->>Val: Executes @Valid Bean Validation

    alt Validation Constraint Fails (@NotNull, @DecimalMin)
        Val-->>ExHandler: Throws MethodArgumentNotValidException
        ExHandler-->>NextJS: 400 Bad Request { success: false, message: "Validation error" }
        NextJS-->>User: Highlights invalid input field in UI
    else Validation Passes
        Ctrl->>Svc: Invokes managerGoalService.createGoal(request)
        Svc->>Svc: Obtains Manager ID from SecurityUtils.getCurrentUserId()
        Svc->>Svc: Enforces Domain Rule: Sum of weights <= 100.00%

        alt Weight Exceeds 100%
            Svc-->>ExHandler: Throws BadRequestException("Total goal weight cannot exceed 100%")
            ExHandler-->>NextJS: 400 Bad Request { success: false, message: "Weight exceeds 100%" }
            NextJS-->>User: Displays Toast Banner "Weight exceeds 100%"
        else Business Rules Validated
            Svc->>Repo: Saves new Goal entity via goalRepository.save(goal)
            Repo->>DB: Executes SQL: INSERT INTO goals (...) VALUES (...)
            DB-->>Repo: Returns generated Primary Key & Timestamps
            Repo-->>Svc: Returns Persisted JPA Entity
            Svc->>Svc: Maps Entity to Immutable GoalResponse Record DTO
            Svc-->>Ctrl: Returns DTO
            Ctrl-->>NextJS: 201 Created wrapped in ApiResponse (Header: X-Request-ID)
            NextJS->>NextJS: Re-renders reactive state
            NextJS-->>User: Displays Success Toast & Updates Goal Meter
        end
    end

    actor Emp as 💼 Employee (e.g. Vamshi / EMP038)
    participant App as 🖥️ ASCEND Application
    actor Mgr as 👔 Manager (e.g. Karthik / MGR015)

    Note over Mgr,App: 1. Initial Goal Allocation
    Mgr->>App: POST /api/manager/goals (Weight: 40%, Status: PENDING_ACCEPTANCE)
    App-->>Emp: Goal renders in Employee Portal

    alt Direct Acceptance Flow
        Emp->>App: PATCH /api/employee/goals/{id}/accept
        App->>App: Transition to ACCEPTED
        Emp->>App: PATCH /api/employee/goals/{id}/progress (Progress: 100%)
        App->>App: Transition to COMPLETED
    else Modification Request Workflow
        Emp->>App: PATCH /api/employee/goals/{id}/modification-request (Reason: Need 2-week extension)
        App->>App: Transition to MODIFICATION_REQUESTED
        App-->>Mgr: Appears in Manager Pending Modifications Panel

        alt Manager Approves Request
            Mgr->>App: PATCH /api/manager/goal-modification-requests/{id}/approve
            App->>App: Goal parameters updated & Status reset to ACCEPTED
            App-->>Emp: Employee dashboard reflects approved new targets
        else Manager Rejects Request
            Mgr->>App: PATCH /api/manager/goal-modification-requests/{id}/reject (Reason: Deadlines cannot be moved)
            App->>App: Goal returns to previous active state (ACCEPTED / IN_PROGRESS)
            App-->>Emp: Employee dashboard shows rejection comment
        end
    end
